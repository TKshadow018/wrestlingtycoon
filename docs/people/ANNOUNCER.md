# Announcers

Announcers improve show presentation. At least one announcer is required to run an event. An announcer can be selected on supported segments, and their effect is applied only when booked.

## Abilities and effects

The announcer skill score averages voice quality, hype delivery, diction, ring knowledge, and popularity. For a booked segment:

- On a match, main event, or title match, broadcast ability can add up to 0.2 match rating.
- On a segment with the announcer, broadcast ability can add up to two fans.
- Main events and interviews require an announcer; title matches can use one optionally.

An announcer does not determine a match winner. The match-rating bonus is capped, and the event result reports actual support contributions.

## Booking and cost

Select the announcer in the event setup for segments that support the role. Announcers are support employees, so taking part in an event incurs an appearance fee; repeated segment use may add a heavy-usage bonus. This is separate from recurring monthly salary on the contract schedule.
