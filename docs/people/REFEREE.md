# Referees

Referees officiate matches. At least one referee is required to run an event, and a referee must be selected for each match segment. A referee is not an in-ring wrestler and does not affect the selected winner.

## Abilities and effects

The referee skill score averages rule knowledge, decision speed, positioning, composure, and popularity. The selected referee's officiating ability can add up to 0.25 match rating. The contribution is capped and appears in the event result.

## Booking and cost

Choose a referee for each standard match, main event, or title match during event setup. Referees are support employees, so taking part in an event incurs an appearance fee; repeated segment use may add a heavy-usage bonus. This is separate from recurring monthly salary on the contract schedule.
